# Thinkdiag 2 — Reverse Engineering

Реверс-инжиниринг OTA-обновлений диагностического адаптера **Thinkcar Thinkdiag 2**.

## Цели
1. Понять логику OTA-обновления из стокового дампа прошивки
2. Распаковать DOWNLOAD.BIN (OTA-пакет)
3. Скрипты запаковки/распаковки для заливки внешним программатором
4. Возможность создавать и тестировать свои OTA-обновления

## Исходные файлы
- `firmware_dump.bin` (GDrive) — ZIP: стоковые S-record образы `TD2.mot`/`DB7.mot` (1МБ флеш 0x00400000-0x00500000) + J-Flash проекты
- `DOWNLOAD.BIN` (GDrive) — ZIP: `{серийник}/DOWNLOAD.bin` + `DOWNLOAD.ini` (Version=V12.05)

## Ключевые выводы (кратко)
- MCU: **Microchip ATSAME70Q20A** (Cortex-M7, 1MB flash @0x00400000, 384KB RAM @0x20400000), SWD
- Бутлоадер "V1.23.004" (TD2) / "V1.22.004" (DB7), IAR, USB CDC ("USBToSerial")
- Приём OTA: бутлоадер сравнивает имя файла с **"DOWNLOAD.BIN"** / **"J2534.BIN"**
- Цели обновления: DOWNLOAD.BIN → app-регион 0x4A0000, J2534.BIN → 0x410000, boot → 0x400000
- Валидация: **MD5 данных + RSA-подпись** (модуль 220Б = 1753 бит, e=65537, PKCS#1 v1.5)
- Транспортный шифр: 8-байтовые блоки (функция 0x407008), контексты в RAM
- Подпись привязана к серийному номеру устройства
